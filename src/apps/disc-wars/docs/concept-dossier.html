Neon Virus Edition — FPS Disc-Combat

Ein infiziertes Grid. Du bist das letzte freie Programm.
Deine einzige Waffe: eine Identity Disc, die von Wänden abprallt, Feinde entrezzt — und zum Bumerang wird. Das System schickt seine Agenten. Du wirfst zurück.

The Pitch

Neon Labyrinth war Erkundung — ruhig, atmosphärisch, das Ziel lag irgendwo im Dunkel. Disc Wars ist das Gegenteil: Action, Bedrängnis, knappe Ressourcen. Derselbe Procedural-Maze-Core, aber jetzt patroullieren echte Agenten mit Zustandsautomaten, Fallen explodieren wenn man draufsteht, und der MCP wartet im Herz des Systems.

Das Neon-Virus-Ästhetik löst das saubere Disney-Tron-Blau ab: Gift-Grün-Emissive, giftig-lila Korridor-Seams, Danger-Pink für alles was tötet. Das Grid sieht aus wie ein Rechner der gerade stirbt.

Kernmechaniken

Mechanik 01
Identity Disc
Taste: Linksklick zum Werfen, Rechtsklick zum Blocken/Parieren.

Die Disc fliegt als Raycaster-basiertes Projektil, prallt von Wänden ab (max. 3 Bounces). Trifft sie einen Agenten: 1 Hit. Kehrt danach zum Spieler zurück (lerp-basierte Heimkehr, nicht physikalisch exakt — fühlt sich besser an). Catch: automatisch wenn nah genug. Miss: Disc liegt auf dem Boden, kurzes Pickup-Delay.
Raycaster TrailRendererBehavior
Mechanik 02
Gegner-System: 3 Typen
Sentinel — Patrouilliert entlang fixer Punkte (PathFollowerBehavior). Wird er getroffen: kurzer Stagger, dann Aggro → Jäger-Modus.

Guardian — Stationär. Rotierender Disc-Angriff (Torus-Hitbox dreht sich). Muss von der Seite/hinten getroffen werden.

Hunter — Verfolgt den Spieler aktiv. Wirft seine eigene Disc zurück (Disc kann pariert werden!). Schnell aber fragil.
StateMachine 3 Typen
Mechanik 03
Fallen
Energy Spike — Aus dem Boden schießende Energie-Zylinder (OscillatorBehavior). ProximitySensor löst aus.

Laser Gate — Rotierende Barriere aus Tube-Geometrie, blockiert Passage rhythmisch.

Corruption Zone — Boden wird giftig-grün, Schaden über Zeit. Kein Instant-Kill — zwingt zur Bewegung.
Fallen ProximitySensorBehavior
Mechanik 04
MCP-Boss
Master Control Program — ein riesiger pulsierender Kubus im Herz von Floor 3. Dreht sich langsam (RotatorBehavior), schickt Wellen von Hunters, feuert Disc-Salven (3 auf einmal, in einem Fächer). Schwachpunkt: leuchtend-weiße Panels an den Seiten. 3 Treffer = Sektor gewonnen. Beim Tod: EmissivePulseBehavior mit massiver Bloom-Explosion.
Boss RotatorBehavior Bloom-Explosion
Mechanik 05
Maze + Progression
3-Floor ProcGen Maze (direkt aus Neon Labyrinth MazeGenerator, erweitert mit neuen CellTypes für Fallen). Jeder Floor hat einen Checkpoint-Beacon. Discs sammeln → Energie für den Boost (kurzes Sprint-Dash). Tod: Respawn am letzten Checkpoint — kein Full-Reset.
MazeGenerator Checkpoints
Mechanik 06
Programm-Rang XP
Jeder Kill, jede eingesammelte Disc, jeder Bounce-Kill (Ricochet-Treffer) gibt XP. XP geht in den globalen Programm-Rang (localStorage, für THE GRID Meta-System). Höhere Ränge: andere Disc-Farbe, andere Seam-Farbe.
Meta-System localStorage

Disc-Mechanik — Technischer Flow

01

Wurf

Spieler drückt LMB. Disc-Objekt wird an Kamera-Position gespawnt, Richtung = normalisierter Camera-Forward-Vektor. TrailRendererBehavior aktiviert (grüner Schweif). Disc-State: FLYING.

02

Flug & Bounce

Jedes Frame: Raycaster.cast() in Flugrichtung. Hit auf Wand → Reflektions-Vektor berechnen (r = d - 2*(d·n)*n). Bounce-Counter++. Nach 3 Bounces: State → RETURNING.

03

Hit auf Agenten

Raycaster trifft Agent-BoundingSphere → Agent verliert HP. ImpactFlashBehavior auf Agent. Disc-State → RETURNING nach Hit. Hunter-Disc-Parry: wenn Spieler RMB gedrückt, eigene Disc im Block-Radius → Hunter-Disc wird reflektiert zurück.

04

Rückkehr

Disc bewegt sich lerp-basiert zur aktuellen Kamera-Position. Wenn nah genug (ProximitySensor): gecatcht, State → IDLE. Verpasst: Disc landet als Mesh auf dem Boden (Pickup-Delay 1.5s, dann wieder werfbar).

05

Bounce Kill

Disc trifft Agenten nach mindestens 1 Bounce → Bonus-XP „Ricochet Kill". Camera-Shake + extra Ton-Pitch-Up. Besonderer Impact-Flash in Cyan statt Grün.

Gegner-KI — State Machine

Sentinel
PATROL → ALERT → FLEE
PATROL: PathFollowerBehavior entlang 3–4 Waypoints. Blickwinkel 90° FOV Check auf Spieler.
ALERT: Läuft auf letzter bekannter Spieler-Position. Eigene Disc nach 2s Aggro-Delay.
FLEE: Unter 30% HP — flieht, ruft Hunter (spawnt neuen).
Guardian
GUARD → ATTACK → STAGGER
GUARD: Stationär, rotiert RotatorBehavior-Hitbox-Torus 360°/4s.
ATTACK: Spieler in Radius → schießt 2 Discs (symmetrisch links+rechts).
STAGGER: Von hinten/Seite getroffen → kurze Stun-Phase, dann zurück zu GUARD.
Hunter
CHASE → THROW → DODGE
CHASE: Verfolgt Spieler direkt (normalized direction, kein Pathfinding — rennt durch offene Korridore).
THROW: In Wurfreichweite → wirft Disc, wartet auf Rückkehr.
DODGE: Spieler-Disc detektiert (ProximitySensor) → kurzer Sidestep.

Risiken

Risiko 01
Disc-Bounce-Feel
Ricochet muss sich befriedigend anfühlen, nicht physikalisch korrekt. Risiko: zu zufällig, unkontrollierbar → frustration. Mitigation: max. 3 Bounces hardcoded, Bounce-Winkel leicht Richtung-Spieler-biased (±10°).
MITTEL
Risiko 02
KI-Pathfinding
Hunter verfolgt per normalized direction — kein A*. Funktioniert in offenen Korridoren, versagt wenn Agent hinter einer Wand steckt. Mitigation: Hunter spawnt nur auf FLOOR-Cells mit freier Sichtlinie.
MITTEL-HOCH
Risiko 03
Light-Budget
Engine: max. 4 PointLights + 4 SpotLights gleichzeitig. Viele Gegner + Fallen mit eigenem Licht = Budget-Overflow. Mitigation: Emissive-Material + Bloom statt PointLights für Fallen/Gegner. Nur Spieler-SpotLight + MCP-PointLight als echte Lichter.
MITTEL

Nächster Schritt

Woche 1, Tag 1: Neuer Showcase-Ordner src/apps/disc-wars/ + Grundstruktur (App.ts, index.ts, Events.ts). Maze aus Neon Labyrinth übernehmen (Copy-Adapt), Neon-Virus-Palette rein. Disc als einfaches Sphere-Objekt werfen + zurückfliegen. Kein Gegner, nur das Maze und die Disc.
